Network and Switching

深度扩展版

第一章：物理层的碰撞

砂拉越大学的 402 机房总是弥漫着一种陈旧的电子味和散热风扇的嗡鸣声。Wilson 瘫坐在人体工学椅上，盯着屏幕上那行刺眼的 Connection Timed Out，那是他这学期第三次在《网络与交换技术》的实验课上遭遇滑铁卢。

"如果我是交换机，我会直接把你这个无效数据包丢进垃圾桶。"

一个清冷且带着一丝戏谑的声音从他头顶落下来。

Wilson 不用回头都知道是谁。Sheena 教授正抱着文件夹站在他身后，她今天穿了一件米白色的真丝衬衫,领口的一枚银色胸针闪着凌厉的光。她才二十八岁，却已经是计算机系的王牌讲师，以"挂科率最高"和"嘴毒"著称。

"Sheena 老师……"Wilson 苦着脸，指着屏幕，"我明明按照你讲的三次握手逻辑去配置了，可它就是握不上啊。"

"那是你理解的'握手'太粗鲁了。"Sheena 弯下腰，从 Wilson 手里夺过鼠标。那一瞬间，她身上那种清冷的柑橘调香水味直接撞进了 Wilson 的呼吸里。

她一边飞速地修改着路由配置，一边毒舌道："你是把 TCP 协议当成你的情书了吗？逻辑混乱，参数错误，连基本的序列号都对不上。Wilson，我真的很怀疑你是怎么考进 CS 系的，靠玄学吗？"

虽然话不好听，但 Wilson 发现，她在他的实验手册上改动时，特意用红笔在边缘写了一行极其秀气的字："基础不牢，地动山摇。去翻书第 85 页，别再让我看到这种低级错误。"

第二章：带宽不足的关怀

Wilson 之所以成为这门课的"钉子户"，并不是因为他笨。大二那年他家里出了变故，为了筹医药费，他整整一个学期都在校外跑外卖，错过了最核心的课程。

那天晚上十点，机房的灯灭了大半，只有 Wilson 这一角还亮着。

"还不滚回去睡觉？指望这台电脑给你发毕业证？"Sheena 拎着包路过，脚步声在空旷的走廊里格外清晰。

Wilson 揉了揉发酸的眼睛，诚实地回答："老师，我得把上次欠的实验补回来，不然这学期又要重修了。"

Sheena 停住了脚步。她看着 Wilson 凌乱的头发和眼下的青色，眼神微微一动，但嘴上依旧不饶人："你是想把我的机房电费刷爆吗？"

她走过来，从包里翻出一块还没开封的巧克力和一罐热咖啡，随手扔在桌上。

"便利店促销买一送一，剩下的。赶紧吃了滚蛋，别在我的实验室里低血糖晕倒，我还要写事故报告，麻烦死了。"

Wilson 看着那罐写着"新品上市"字样的咖啡，心里嘀咕：这新品从来不打折，哪来的买一送一？ 但看着 Sheena 略显局促转过身的背影，他突然觉得，这位高冷的老师好像也没有那么难以接近。

第三章：弱信号的共振

期中考试前夕，一场突如其来的暴雨困住了还没来得及撤离的学生。

机房的窗户被狂风吹得砰砰作响，突然"啪"的一声，全校停电。黑暗瞬间像潮水一样淹没了整个空间，唯独 UPS 应急灯发出微弱的红光。

"啊！"

一声惊呼从讲台方向传来。Wilson 借着手机微光看去，发现刚才还威风八面的 Sheena 教授，竟然缩在讲台后面，身体微微颤抖。

"Sheena 老师？" Wilson 走过去，发现她紧闭着双眼，脸色苍白。

"别过来……我，我只是对黑暗环境有轻微的……应激反应。"她即便在这种时候，还在试图维持她身为教授的尊严。

Wilson 没理会她的嘴硬。他走过去，并排坐在她身边的冰冷地板上，用自己宽大的卫衣袖子轻轻碰了碰她的手臂。

"老师，你可以把我当成一台备用电源。"Wilson 声音低沉，带着一点少年特有的磁性，"只要你连接上我，信号就不会中断。"

Sheena 愣住了，半晌，她竟然没有推开他，反而把头埋进了膝盖里，声音闷闷的："你要是考不及格，我就把这台'电源'给报废了。"

"那你可得好好给我补课。"Wilson 趁机握住了她冰凉的手指，"我这个'硬件'配置不错，就是'软件'驱动还没安装好。"

那一夜，在黑暗的机房里，他们聊了很多。Sheena 讲了她在国外留学的孤独，Wilson 讲了他家里的变故。原本冰冷的师生关系，在那个雨夜被一种名为"共情"的协议给重写了。

第四章：满分校验

期末考场上，Sheena 穿着一身干练的黑色长裙巡考。

当她走到 Wilson 桌边时，Wilson 故意抬起头，冲她眨了眨眼。Sheena 狠狠地瞪了他一眼，用口型无声地说了句："好好写你的卷子！"但转身时，她的嘴角却无法抑制地勾起了一抹弧度。

出成绩那天，Wilson 没在系统里查分，而是直接去了办公室。

"老师，我查不到成绩。"Wilson 站在门口，一脸严肃。

Sheena 正在录入系统，闻言挑了挑眉："不可能，我亲自录入的，你这次考得……还算像个人样。"

"但我查的是我的人生分值。"Wilson 走到她桌前，递过去一份打印好的"录取通知书"。

Sheena 疑惑地接过一看，上面用代码写着：

class Relationship:
 def __init__(self):
  self.status = "Single"
  self.teacher = "Sheena"
  self.student = "Wilson"

 def update_to_lovers(self):
  if Wilson.final_exam >= 50:
  self.status = "In Love"
  return "请求建立长久连接，不接受超时重传。"

print(Relationship().update_to_lovers())

Sheena 看完，半天没说话。她摘下眼镜，揉了揉有些发红的眼睛，然后拿起桌上的红色水彩笔，在那张纸上画了一个大大的、极其认真的红勾。

"Wilson，你这代码写错了。"她抬头看他，眼里闪烁着温柔的光，"这不叫'录取通知书'，这叫'终身合同'。"

"那你要签吗？教授。"

"签啊。"Sheena 站起身，隔着办公桌拉住了他的领口，恶狠狠地（却又温柔地）说，"但如果你毕业后敢偷偷改密码，我就把你的档案给拉黑了！"
